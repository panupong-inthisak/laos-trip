# ทริปลาว 3 วัน 2 คืน: เวียงจันทน์ · วังเวียง · เมืองเฟือง

เว็บนำเสนอทริป (React + Vite + framer-motion)

- แก้แผน เวลา ราคา เช็คลิสต์ ได้ที่ `src/data.js` ไฟล์เดียว
- รูปอยู่ใน `public/img` (จาก Wikimedia Commons ดูเครดิตท้ายเว็บ) จะเปลี่ยนรูปให้วางไฟล์ `.jpg` ชื่อเดิมทับ หรือเพิ่มชื่อใหม่แล้วใส่ใน `img:` ของ data.js

## รันให้เพื่อนในวงแลนดู

```bash
npm install
npm run dev
```

เปิดลิงก์ `Network:` ที่ขึ้นในเทอร์มินัล เช่น `http://192.168.1.187:5173`

ถ้าเครื่องอื่นเข้าไม่ได้ ให้กด Allow ตอน Windows Firewall ถาม หรืออนุญาต Node.js บน Private network

## เวอร์ชันพร้อมใช้ (เร็วกว่า)

```bash
npm run build
npm run preview
```
